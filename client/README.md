# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and robust linting.  It prioritizes performance and developer experience.

**Key Improvements:**

* **Enhanced Linting:**  Stricter ESLint configuration with support for TypeScript, React hooks, and accessibility rules.  Includes automatic code formatting.
* **Optimized Dependencies:**  Minimized dependencies to improve build speed and reduce bundle size.
* **Improved TypeScript Support:**  Full TypeScript support with type checking and improved developer tooling.
* **Testing Framework Integration:**  Basic setup for Jest and React Testing Library for unit and integration testing.
* **Styled-Components or CSS Modules (Choose One):**  Provides a choice between styled-components for CSS-in-JS or CSS Modules for modular CSS.


**To get started:**

1.  **Install dependencies:** `npm install` or `yarn install`
2.  **Start the development server:** `npm run dev` or `yarn dev`
3.  **Build for production:** `npm run build` or `yarn build`
